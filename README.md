# Rental Management System

A web-based rental management system built with Node.js, Express, and EJS that allows users to list and book properties.

## 🚧 Project Status
This project is currently under development. Features are being added regularly.

## 🚀 Features
- Add new property listings
- View all listings
- Edit listings
- Delete listings

## 🛠️ Tech Stack
- Node.js
- Express.js
- EJS
- MongoDB

## 📁 Folder Structure
- models/ → database schemas
- views/ → EJS templates
- public/ → static files (CSS, JS)
- utils/ → helper functions

## ▶️ Run Locally

```bash
npm install
nodemon app.js
